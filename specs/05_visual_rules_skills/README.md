# Визуальные правила, UI/UX и Дизайн-Система

## Назначение раздела

Этот раздел хранит визуальные спецификации, интерфейсные соглашения, референсы UI/UX и токены дизайн-системы для проекта кавказского кафе в Каире.

Раздел связывает бизнес-спецификации (`Global Spec`, `Functional Map`, `Feature Specs`) с технической и UI-реализацией.

---

## Документы раздела

1. `UI_UX_Design_System.md` — Утвержденные UI/UX-ориентиры, референсы с Refero.design (Sunsama, DoorDash, Yelp/Limón), цветовую палитру, типографику и правила интерфейса.
