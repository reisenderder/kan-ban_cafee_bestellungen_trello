# Активные планы разработки

В этой папке хранятся планы, работа по которым еще не завершена или еще не подтверждена пользователем после ручного тестирования.

## Правила

1. Каждый новый план разработки создается в этой папке.
2. План остается здесь, пока не завершены все его группы и критерии, даже если промежуточная группа уже опубликована и смержена.
3. Для промежуточных групп разрешены `git add`, commit, push, pull request и merge после явного запроса пользователя; они не завершают весь план.
4. Если план состоит из нескольких групп, каждая группа выполняется в отдельной ветке от актуального `main`, а следующая начинается только после merge предыдущей и синхронизации `main`.
5. Успешные автоматические тесты или завершение отдельной группы сами по себе не завершают план.
6. После выполнения всего плана, ручной проверки итогового результата, явного подтверждения пользователя о завершении всего плана и просьбы подготовить его финальную публикацию план перемещается в `../completed/` до финального push, который делает изменения готовыми к merge.
7. В том же completion commit обновляются статус плана, `../README.md`, все ссылки на файл и соответствующие журналы в `../../roadmap/`.
