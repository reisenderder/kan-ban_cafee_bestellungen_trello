# Завершенные планы разработки

В этой папке хранится история планов, реализация которых завершена и подтверждена пользователем после ручного тестирования.

## Правила

1. План переносится сюда из `../active/` только после выполнения всех его групп и критериев, ручной проверки итогового результата, явного подтверждения пользователя о завершении всего плана и просьбы подготовить его финальную публикацию.
2. Завершение или публикация промежуточной группы для переноса недостаточны.
3. Промежуточные commit, push, pull request и merge допускаются, пока план остается активным.
4. После выполнения всех условий пункта 1 перенос выполняется до финального push, который делает изменения готовыми к merge.
5. Одновременно фактически выполненные работы записываются в соответствующие журналы `../../roadmap/`.
6. В перенесенном плане фиксируется завершенный статус, а перенос и roadmap включаются в финальный completion commit.
7. Завершенный план сохраняется как исторический документ и не удаляется.
8. Новая доработка оформляется отдельным активным планом, а не перезаписывает завершенный план.
